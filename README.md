# NOVAIL IA – Cybersécurité simple, automatisée et accessible

> Démo vidéo : https://youtu.be/z0IItK8lJKY

## Présentation

NOVAIL IA est une solution de cybersécurité conçue pour aider les entreprises à protéger leurs données sensibles sans complexité.
Elle automatise la surveillance et la protection des informations en temps réel.

## Problématique

Les PME manipulent des données sensibles sans avoir les ressources ou l'expertise pour les protéger. Les solutions traditionnelles sont trop complexes et coûteuses.

## Solution

- Surveillance automatisée des données
- Identification des informations sensibles
- Protection contre les accès non autorisés
- Utilisation intuitive, sans configuration technique

## Technologies utilisées

| Technologie | Rôle |
|---|---|
| HTML5 | Structure des pages |
| CSS3 | Mise en page, animations, glassmorphism |
| JavaScript (ES6+) | Interactivité et animations |
| Three.js | Animations 3D immersives |
| WebGL / OGL | Effets visuels avancés (Iridescence) |
| Framer | Composants interactifs (Passwordle) |
